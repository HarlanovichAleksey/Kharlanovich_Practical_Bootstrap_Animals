# Практическая работа №1 (Тема 3) — Приют для животных на Bootstrap

**Автор:** Харланович Алексей, ПИУКИС-23

## Описание
Адаптивный сайт «Приют для животных "Добрые лапы"» на **Bootstrap 5**.
Реализованы все требования практической работы.

## Что реализовано
- **Семантические теги:** `<header>`, `<nav>`, `<section>`, `<footer>`;
- **Липкое меню** — класс `fixed-top` + `navbar-expand-lg`;
- **Бургер-меню** — автоматически на экранах < 992px через `navbar-toggler`;
- **Слайдер** — Bootstrap Carousel, кастомизированы только стрелки навигации;
- **Секция «О приюте»** — Bootstrap Grid (row/col);
- **Секция «Наши питомцы»** — карточки (`card`, `row-cols-*`), адаптивные;
- **Форма усыновления** — с валидацией (`needs-validation`, `invalid-feedback`);
- **Font Awesome** — иконки логотипа, контактов, соцсетей;
- **Максимум классов Bootstrap**, кастомный CSS — только для стрелок слайдера, отступа под меню и высоты картинок.

## Технологии
- Bootstrap 5.3.3 (CDN)
- Font Awesome 6.7.2 (CDN)
- HTML5 (семантические теги)
- JavaScript (валидация формы)

## 📁 Структура проекта
- `index.html` — вся разметка;
- `img/` — изображения для слайдера и карточек.
